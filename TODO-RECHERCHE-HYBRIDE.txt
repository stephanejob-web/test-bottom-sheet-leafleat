  IMPLÉMENTATION DÉTAILLÉE
═══════════════════════════════════════════════════════════════════════════

1️⃣ MODIFIER LE useEffect DE RECHERCHE (ligne ~92-116 dans index.tsx)

   Logique actuelle :
   ------------------
   - Cherche uniquement dans cityCoordinates
   - Si pas trouvé → Ne fait rien

   Nouvelle logique :
   ------------------
   a) Chercher d'abord dans cityCoordinates (garde l'existant)
   b) SI PAS TROUVÉ :
      - Filtrer allChurches par :
        * church.city.toLowerCase().includes(searchLower)
        * church.address.toLowerCase().includes(searchLower)
        * church.name.toLowerCase().includes(searchLower)
      - Si églises trouvées :
        * Calculer le centre géographique (moyenne des lat/lng)
        * Centrer la carte sur ce point
        * setSearchCenter(centerPoint)

2️⃣ EXEMPLE DE CODE

   useEffect(() => {
     if (debouncedSearchQuery.trim() === '') {
       setSearchCenter(null);
       return;
     }

     const searchLower = debouncedSearchQuery.toLowerCase().trim();

     // Étape 1 : Chercher dans cityCoordinates
     const cityKey = Object.keys(cityCoordinates).find(city =>
       searchLower.includes(city) || city.includes(searchLower)
     );

     if (cityKey) {
       // Ville trouvée dans cityCoordinates
       const coords = cityCoordinates[cityKey];
       setSearchCenter(coords);
       mapRef.current?.animateToRegion({...});
     } else {
       // Étape 2 : Chercher dans les églises
       const matchingChurches = allChurches.filter(church =>
         church.city.toLowerCase().includes(searchLower) ||
         church.address.toLowerCase().includes(searchLower) ||
         church.name.toLowerCase().includes(searchLower)
       );

       if (matchingChurches.length > 0) {
         // Calculer le centre géographique
         const centerLat = matchingChurches.reduce((sum, c) => sum + c.latitude, 0) / matchingChurches.length;
         const centerLng = matchingChurches.reduce((sum, c) => sum + c.longitude, 0) / matchingChurches.length;

         const center = { latitude: centerLat, longitude: centerLng };
         setSearchCenter(center);

         mapRef.current?.animateToRegion({
           latitude: centerLat,
           longitude: centerLng,
           latitudeDelta: 0.15,
           longitudeDelta: 0.15,
         }, 1000);
       }
     }
   }, [debouncedSearchQuery]);
